## Commands

Package manager is npm (`package-lock.json` is present).

- `npm run dev` — Next.js dev server on http://localhost:3000 (Turbopack)
- `npm run build` — production build; also runs type generation for `.next/types`
- `npm run start` — serve the production build (run `build` first)
- `npm run lint` — runs `eslint` directly (ESLint 9 flat config in `eslint.config.mjs`)
- Type check: no script defined; use `npx tsc --noEmit`

There is no test framework or test script configured, so there is no way to run a single test yet.

## Stack and configuration

- Next.js 16 with the App Router (`app/` directory), React 19, TypeScript (strict), Tailwind CSS v4.
- Tailwind is wired through `@tailwindcss/turbopack` in `next.config.ts` (a `*.css` loader rule), and `app/globals.css` starts with `@import "tailwindcss"`.
- `next.config.ts` enables `cacheComponents: true`, `partialPrefetching: true`, and `experimental.agentFeedback`. Keep these in mind when adding data fetching or caching, since they change how Next prerenders and caches pages.
- `tsconfig.json` maps `@/*` to the project root.
- `app/layout.tsx` uses the global `LayoutProps<"/">` type, which is generated by Next into `.next/types`. If type errors mention it, run `npm run dev` or `npm run build` once to regenerate types.
- `next-env.d.ts`, `.next/`, and `node_modules/` are generated or ignored; don't edit them.

## Architecture

The project is still the default scaffold. Routing is file-based and the whole app currently lives in:

- `app/layout.tsx` — root layout: loads Geist and Geist Mono via `next/font/google` as CSS variables (`--font-geist-sans`, `--font-geist-mono`), sets `<html lang="en">`, and holds the page metadata.
- `app/page.tsx` — the home route (`/`), a single server component with the boilerplate content.
- `app/globals.css` — Tailwind import plus the color tokens `--background` and `--foreground`. These are mapped into Tailwind through `@theme inline` and switched to dark values under `prefers-color-scheme: dark`. Theme colors should go through these tokens.
- `public/` — static SVG assets referenced by absolute paths such as `/next.svg`.

Goal: this is meant to become a personal portfolio. The design reference is the vcdesign.team site: a light, minimal layout with large light-weight sans-serif headings, pill-shaped tags, and animated text reveals. The boilerplate in `app/page.tsx` will be replaced rather than extended.
